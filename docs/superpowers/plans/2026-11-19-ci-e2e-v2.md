# CI e2e, revision 2 — Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.
**Spec:** `docs/superpowers/specs/2026-11-19-ci-e2e-design.md` (Revision 2 binds)

## Review Focus
- An image job that fails before its runner starts: e2e job must not wait forever and no runner stays registered.
- A job picked by the wrong runner, or the e2e runner taking a different job.
- Publish credentials or the App key reachable from the VM/container that runs job code.
- Dependabot and fork PRs: no secrets, must skip cleanly, not fail.
- Re-run all jobs: new nonce, new labels, still works.

### Task 1: workflow
- [ ] `resolve` outputs `nonce`; `e2e` job runs-on `[ghr-e2e-<nonce>-<release>-<target>]`; skip condition includes dependabot.
- [ ] `image`: create-github-app-token (pinned SHA) → registration token → container gets only RUNNER_TOKEN + NO_DEFAULT_LABELS; identity grep; always() stop + API delete; cache-to.
- [ ] `publish` job with registry secrets; `image` loses write permissions; `cancel-orphans` job.
- [ ] actionlint; push; PR CI green with all 4 e2e jobs; summary shows timings; 0 runners left.
- [ ] Negatives: broken build on one variant → run cancelled by cancel-orphans, 0 runners; job-step failure → failure, publish skipped.
### Task 2: docs, review, merge
- [ ] Building-and-extending (fix lost backslashes), Security line; final review; merge.
