# CI end-to-end job Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every freshly built amd64 image registers as an ephemeral runner (GitHub App auth), runs a real job, and gates publishing on it.

**Architecture:** `build.yml` gets an `e2e` matrix job queued on a per-run label, and the `image` job gets an "e2e runner" step that starts the image as that runner and waits for it, plus an orphan-cancel step.

**Tech Stack:** GitHub Actions, Docker on `ubuntu-latest`, `ghr` App auth.

**Spec:** `docs/superpowers/specs/2026-11-19-ci-e2e-design.md`

## Global Constraints

- Label: `ghr-e2e-${{ github.run_id }}-${{ github.run_attempt }}-${{ matrix.release }}-${{ matrix.target }}`.
- Secrets: `E2E_APP_ID`, `E2E_APP_PRIVATE_KEY`. App permission: repository Administration read and write, installed only on `marr-cloud/chiseled-runner`.
- Runner env: `REPO_URL=https://github.com/${{ github.repository }}`, `EPHEMERAL=true`, `DISABLE_AUTO_UPDATE=true`, `RUNNER_NAME=e2e-<release>-<target>`.
- Wait: `timeout 900 docker wait`; pass = exit 0 AND log contains `completed with result: Succeeded`; always `docker stop -t 60` then print logs.
- Gate: repo variable `E2E_ENABLED == 'true'` (deviation from the spec's "skip if E2E_APP_ID is empty": job-level `if:` cannot read secrets).
- Fork PRs: condition `github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository` on both jobs' e2e parts. Missing `E2E_APP_ID` → skip, not fail.
- All new `uses:` pinned by SHA (checkout v7 `3d3c42e5aac5ba805825da76410c181273ba90b1`, setup-node: resolve latest major SHA at implementation time). `actions/checkout@v4` stays unpinned on purpose (it is the node20 probe).
- `actions: write` only on the `image` job.

## Review Focus

- Image build fails before the runner starts: the queued `e2e` job must not stay queued; the run ends cancelled. Task 4.
- The e2e job fails: `image` must fail and skip login/publish. Task 2 Step 4.
- Runner never picks up (e.g. label mismatch): `image` fails after 15 min and the runner is deregistered (0 runners). Task 2 Step 5.
- Secrets absent (before the App exists, or fork PR): both e2e parts skip; build and publish behave as today. Task 1.
- `docker` variants: workspace bind mount from a job container must resolve on the host. Task 3.

### Task 1: Skeleton with skips (testable before the App exists)

**Files:** Modify `.github/workflows/build.yml`.

- [ ] **Step 1:** Add job `e2e` (`needs: [resolve]`, same matrix as `image`, `if: vars.E2E_ENABLED == 'true' && <fork condition>`, `runs-on: [self-hosted, <label>]`, `timeout-minutes: 15`) with steps from Task 2 Step 1 stubbed as one `run: echo e2e`. (A job-level `if:` cannot read secrets; without this gate the job would stay queued forever.)
- [ ] **Step 2:** In `image`, step `e2e runner` after "Smoke tests" with the same `if:` as the `e2e` job, and `env: APP_ID: ${{ secrets.E2E_APP_ID }}`; first line `[ -n "$APP_ID" ] || { echo "E2E_ENABLED is true but E2E_APP_ID is empty" >&2; exit 1; }` (enabled without secrets is a misconfiguration, fail loudly).
- [ ] **Step 3:** `actionlint` clean; push branch, open PR. Expected: `e2e (*)` jobs skipped, `image (*)` pass, summary says e2e skipped.
- [ ] **Step 4: Commit** "CI: e2e job skeleton, skipped until E2E_ENABLED".

### Task 2: Runner hosting and the real job (slim)

**Prerequisite:** user created the App, set `E2E_APP_ID`, `E2E_APP_PRIVATE_KEY`, and variable `E2E_ENABLED=true`.

- [ ] **Step 1:** `e2e` job steps: checkout v7 pinned (default creds), checkout v4 `path: v4`, `run` asserting `hashFiles('go.mod')` non-empty, setup-node (pinned, `node-version: 22`) then `node -v`, `run: test -z "${APP_PRIVATE_KEY:-}${APP_ID:-}"`, `run: git -C v4 submodule status`.
- [ ] **Step 2:** `image` step `e2e runner` per Global Constraints, `APP_PRIVATE_KEY` via env from the secret (never echoed). Record `t0` before `docker run`.
- [ ] **Step 3:** Push. Expected: all 4 `e2e` jobs succeed (docker variants have no docker steps yet), all `image` pass, 0 runners left (`gh api repos/marr-cloud/chiseled-runner/actions/runners -q .total_count`).
- [ ] **Step 4 (negative):** temporarily add `run: exit 1` to `e2e`; push. Expected: `image` fails at `e2e runner`, publish steps skipped. Revert.
- [ ] **Step 5 (negative):** temporarily change the runner's LABELS to a wrong label; push. Expected: `image` fails after 900 s, runner deregistered (0 runners), `e2e` jobs cancelled by Task 4's step (if Task 4 not done yet, cancel the run manually). Revert. Ruling allowed: shorten the timeout via env for this test only.
- [ ] **Step 6: Commit** "CI: run a real job on each image before publishing".

### Task 3: Docker variants

- [ ] **Step 1:** `e2e runner` for `target == docker`: `-v /var/run/docker.sock:/var/run/docker.sock --group-add "$(stat -c %g /var/run/docker.sock)"`, `sudo install -d -o 1001 -g 1001 /tmp/runners`, `-v /tmp/runners:/tmp/runners -e RUNNER_WORKDIR_ROOT=/tmp/runners`.
- [ ] **Step 2:** `e2e` steps with `if: matrix.target == 'docker'`: `docker run --rm hello-world`; `echo ok > probe && docker run --rm -v "$GITHUB_WORKSPACE:/w" busybox cat /w/probe` expecting `ok`.
- [ ] **Step 3:** Push. Expected: docker variants run both steps successfully.
- [ ] **Step 4: Commit** "CI: e2e covers Docker jobs on -docker images".

### Task 4: Orphan cancel

- [ ] **Step 1:** `image` gets `permissions: actions: write` added; final step `if: (failure() || cancelled()) && vars.E2E_ENABLED == 'true'` running `gh run cancel ${{ github.run_id }}` with `GH_TOKEN: ${{ github.token }}`.
- [ ] **Step 2 (negative):** temporarily make the Build step fail (bad `RUNNER_SHA256_AMD64`); push. Expected: run ends `cancelled`, no `e2e` job left queued, 0 runners. Revert.
- [ ] **Step 3: Commit** "CI: cancel the run when no e2e runner will come".

### Task 5: Startup numbers

- [ ] **Step 1:** In `e2e runner`, poll logs for `Listening for Jobs` and `Running job` and append `| <release>/<target> | listen N s | job picked up N s |` to `$GITHUB_STEP_SUMMARY`.
- [ ] **Step 2:** Push. Expected: 4 rows with numbers.
- [ ] **Step 3: Commit** "CI: report runner startup times".

### Task 6: Docs, merge, verify

- [ ] **Step 1:** Building-and-extending "End-to-end check": CI does it; how to set up the App (permissions, install scope, secrets, `E2E_ENABLED`); "Re-run all jobs" note. Security: the e2e runner is ephemeral, per-run label, skipped on fork PRs. Troubleshooting: e2e timeout causes.
- [ ] **Step 2:** Link check (each `](X.md` in docs/README resolves). Commit "Document the CI e2e job".
- [ ] **Step 3:** Final review, then squash-merge; the `main` run: e2e success for 4 variants, then publish succeeds; 0 runners left.
